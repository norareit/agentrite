# agentrite

This package is a pointer. It holds the name `agentrite` on the npm registry and installs nothing useful.

`agentrite` is a command of AgentRite, a kit for running coding agents by a fixed process. AgentRite is the package
`@ritenoar/agentrite`. It is installed from a release URL, not from the npm registry, and the command to install it is
in the README at https://bitbucket.org/ritenoar/agentrite

Once AgentRite is installed in a project, `npx agentrite` runs the kit's own command. Without it, `npx agentrite`
fetches this package, which prints the above and exits with an error.
